## Screenshot Guidelines

### Technical Requirements
- **Format**: PNG or JPG
- **Resolution**: Minimum 1080x1920 (Full HD)
- **File Size**: Under 2MB per image
- **Quality**: High quality, clear text

### Content Guidelines
- Use real data (not Lorem Ipsum)
- Show actual app functionality
- Include different message types in chat
- Show both light and dark themes if applicable
- Capture error states and loading states

### Naming Convention
- Use descriptive names: `feature_description.png`
- Use lowercase with underscores
- Be consistent with naming

## How to Take Screenshots

### Android
1. Open the app on your device/emulator
2. Navigate to the desired screen
3. Use device screenshot function (Power + Volume Down)
4. Or use Android Studio's screenshot tool

### iOS Simulator
1. Open the app in iOS Simulator
2. Navigate to the desired screen
3. Use Device > Screenshot in simulator menu
4. Or use Cmd + S

### Flutter Tools
```bash
# Take screenshot using Flutter tools
flutter screenshot
```
